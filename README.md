# internetmatt.github.io

Parking page for [internetmatt.com](https://internetmatt.com): wordmark plus `hello@internetmatt.com`.

Static site, no build. `public/` is published as-is to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

- `public/index.html` — the page
- `public/parking-shell.css`, `public/parking-player.js` — shared parking shell and LED player (copied from the Projecto parking surface)
- `public/CNAME` — custom domain
